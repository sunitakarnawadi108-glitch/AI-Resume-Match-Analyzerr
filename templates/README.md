# AI Resume Match Analyzer

AI Resume Match Analyzer is a Python Flask web application that compares a resume with a job description.

## Features

- Upload PDF resume
- Analyze resume skills
- Compare skills with job requirements
- Calculate match score
- Show matched skills
- Show missing skills
- Give improvement suggestions
- Download analysis report

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- PyPDF2

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

python app.py
