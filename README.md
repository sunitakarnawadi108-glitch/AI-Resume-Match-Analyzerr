# 🤖 AI Resume Match Analyzer

A Python Flask web application that analyzes a resume against a job description and identifies matching skills, missing skills, and improvement suggestions.

## ✨ Features

- 📄 Upload PDF resume
- 💼 Enter job description
- 🔍 Extract resume text
- 🧠 Detect technical skills
- 📊 Calculate resume match score
- ✅ Show matched skills
- ❌ Show missing skills
- 💡 Give improvement suggestions
- 📥 Download analysis report
- 📱 Responsive web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- PyPDF2
